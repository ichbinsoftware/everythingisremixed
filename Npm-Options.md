# Npm Packaging Plan: `everything-is-remixed`

This document outlines the strategy for packaging the EVR Mixer as a monolithic npm library named `everything-is-remixed`.

## Ecosystem Context
The project serves as the **Audio Engine Layer** for the existing **[@ichbinsoftware/everything-is-free](https://github.com/ichbinsoftware/everythingisfree)** data package.
- **`everything-is-remixed`**: Web Audio logic, Sync, FX, UI, and Visualizer.
- **Integration**: Designed to consume track/stem data objects from the metadata package.

---

## Package Structure
The package will reside in a `/package` directory at the repository root. This allows the main Cloudflare Worker app to remain "build-less" while providing a professional, bundled version for npm.

```bash
evr/
├── package/                # The NPM package root
│   ├── src/                # Library source (synced from root /src)
│   │   ├── core/           # AudioEngine, MixerState, Transport, Loader
│   │   ├── ui/             # Templates, WaveformRenderer, CSS
│   │   ├── visualizer/     # Holograph, Holographic Worker
│   │   └── index.js        # Main entry point (exports everything)
│   ├── dist/               # Bundled assets (Generated by Vite)
│   ├── package.json        # NPM metadata
│   ├── vite.config.js      # Build configuration
│   └── README.md           # Library-specific documentation
├── src/                    # Original app source
└── ...
```

## Using Vite for the Build Pipeline
Vite is the recommended tool for this project because it handles the complex parts of modern web libraries (Workers and CSS) with minimal configuration.

### 1. Library Mode Configuration
Vite will be configured in "Library Mode" to produce two formats:
- **ESM (`.mjs`)**: For modern bundlers (Webpack 5, Vite, Esbuild).
- **UMD (`.js`)**: For direct `<script>` tag usage in the browser.

### 2. Solving the Web Worker Problem
The holographic visualizer relies on a separate Web Worker file. In a standard npm package, this is difficult for users to host.
- **Vite Solution**: We will use `vite-plugin-comlink` or Vite's built-in `?worker&inline` query.
- **Outcome**: The worker code is turned into a Base64/Blob URL string and embedded directly into the main JavaScript bundle. The user doesn't have to host a separate file.

### 3. CSS Injection
The mixer's UI depends on specific styles.
- **Vite Solution**: Use `vite-plugin-css-injected-by-js`.
- **Outcome**: When a user imports the library, the CSS is automatically injected into the document head. No manual `<link>` tag is required.

---

## Proposed `vite.config.js`
```javascript
import { defineConfig } from 'vite';
import { resolve } from 'path';
import cssInjectedByJsPlugin from 'vite-plugin-css-injected-by-js';

export default defineConfig({
  plugins: [cssInjectedByJsPlugin()],
  build: {
    lib: {
      entry: resolve(__dirname, 'src/index.js'),
      name: 'EverythingIsRemixed',
      fileName: (format) => `everything-is-remixed.${format}.js`,
      formats: ['es', 'umd']
    },
    rollupOptions: {
      // Ensure the worker is inlined
      output: {
        inlineDynamicImports: true
      }
    }
  },
  worker: {
    format: 'es',
    plugins: [] // You can add plugins here specifically for the worker
  }
});
```

## Main Entry Point (`index.js`)
The monolithic entry point will export all core classes and UI components, allowing for both "Full Mixer" and "Headless" usage.

```javascript
// Core Engine
export { AudioEngine } from './core/mixer-audio.js';
export { MixerState } from './core/mixer-state.js';
export { TransportController } from './core/mixer-transport.js';
export { StemLoader } from './core/mixer-loader.js';

// UI & Visuals
export { UIBuilder } from './ui/mixer-ui.js';
export { WaveformRenderer } from './ui/mixer-waveform.js';
export { Holograph } from './visualizer/mixer-visualizer.js';

// Constants
export * from './core/mixer-constants.js';
```

---

## Usage Example
```javascript
import { AudioEngine, StemLoader, UIBuilder } from 'everything-is-remixed';
import { getTrack } from '@ichbinsoftware/everything-is-free';

const track = getTrack('Hydrogen');
const engine = new AudioEngine();
const loader = new StemLoader(engine);

// Initialize UI
const ui = new UIBuilder(document.getElementById('mixer-container'));

// Load and Play
await loader.loadStems(track.stems, track.id);
```

## Next Steps
1. **Initialize**: Run `npm init` inside a new `/package` folder.
2. **Setup Vite**: Install `vite` and `vite-plugin-css-injected-by-js`.
3. **Refactor Paths**: Update `mixer-visualizer.js` to use an inline worker import:
   `import HolographicWorker from './mixer-holographic-worker.js?worker&inline'`.
4. **Build & Test**: Run `npx vite build` and verify the `dist/` folder works in a clean HTML file.
